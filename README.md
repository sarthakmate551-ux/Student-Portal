# Student Portal Mini Project

## Project Description
Student Portal is a C++ based student
record management system.

## Features
1. Add Student
2. Search Student
3. Display Student Records
4. Update Student Details
5. Delete Student
6. Add and Update Marks
7. Calculate Percentage and Grade
8. Save and Load Records

## Technologies Used
- C++
- Object Oriented Programming
- STL Vector
- File Handling
- Exception Handling

## Compilation
g++ -std=c++17 main.cpp -o StudentPortal

## Execution
Windows: StudentPortal.exe

## Data Storage
Student records are stored in students.csv.
